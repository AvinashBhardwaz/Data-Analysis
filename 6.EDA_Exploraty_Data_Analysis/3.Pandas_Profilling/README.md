# Pandas Profiling for Exploratory Data Analysis

## Overview
This project demonstrates how to use the pandas-profiling library to generate a comprehensive profile report for a given dataset. The report includes detailed statistics, visualizations, and insights, making it a valuable tool for exploratory data analysis (EDA).

## Contents
- Loading the dataset
- Generating the profile report
- Saving the report to an HTML file

## Requirements
To run this project, you will need:
- Python 3.x
- pandas library
- pandas-profiling library

You can install the required libraries using pip:

```bash
pip install pandas pandas-profiling
